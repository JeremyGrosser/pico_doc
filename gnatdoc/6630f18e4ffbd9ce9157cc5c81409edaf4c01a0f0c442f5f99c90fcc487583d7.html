   REFDIV        : CS_REFDIV_Field := 16#1#;

end record;
Record fields
REFDIV

unspecified

Reserved_6_7

Passes the reference clock to the output instead of the divided VCO. The VCO continues to run so the user can switch between the reference clock and the divided VCO but the output will glitch when doing so.

PLL_Peripheral

type PLL_Peripheral is record
   CS        : aliased CS_Register;
   PWR       : aliased PWR_Register;
   FBDIV_INT : aliased FBDIV_INT_Register;
   PRIM      : aliased PRIM_Register;
end record;
Record fields
CS

Controls the PLL power modes.

PWR

Feedback divisor\n (note: this PLL does not support fractional division)

FBDIV_INT

Controls the PLL post dividers for the primary output\n (note: this PLL does not have a secondary output)\n the primary output is driven from VCO divided by postdiv1*postdiv2
