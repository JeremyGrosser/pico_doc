Description

This driver only supports 7-bit I2C addresses The HAL.I2C.I2C_Address LSB is the R/W bit, so a 7-bit address is shifted left 1 The R/W bit is ignored by the driver. Ex. A device with bus address 2#1010_000# should set Addr => 2#1010_0000#
